Diagnostic Reference

Troubleshooting & Questions

How do I open the Antigravity Web GUI? +
Run agy-gui in Termux for active foreground mode, or run agy-service start to run headlessly in the background. Your default Android browser opens directly to http://localhost:4400.
Resolving `bash: agy: command not found` +
Ensure your shell profile exports the local bin directories: run echo 'export PATH="$HOME/.local/bin:$PREFIX/bin:$PATH"' >> ~/.bashrc && source ~/.bashrc.
Site cannot be reached on localhost:4400 +
Check if the server is active using agy-service status. If inactive, inspect logs using agy-service logs. Verify that $PREFIX/etc/hosts contains 127.0.0.1 localhost.
Termux process killed when minimized +
Execute termux-wake-lock in Termux. In Android Settings > Apps > Termux > Battery, set optimization to Unrestricted to bypass the Android Phantom Process Killer.
OAuth browser tab does not redirect +
Re-link the system browser opener: ln -sf $(which termux-open-url) $PREFIX/bin/xdg-open. Tokens are safely stored at ~/.gemini/antigravity-cli/antigravity-oauth-token.
